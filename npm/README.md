# Devin CLI

Devin for Terminal: https://docs.devin.ai/cli

```sh
npm install -g devin
devin
```

To update, run `npm install -g devin@latest`.

The package contains a small launcher; the native binary for your platform is
installed from the npm registry as an optional dependency (macOS, Linux and
Windows on x64 and arm64). Nothing is downloaded at install time outside the
registry, so it works with registry mirrors.
